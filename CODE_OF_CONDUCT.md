# Código de Conduta

Este projeto exige comunicação respeitosa, linguagem não estigmatizante e proteção rigorosa de participantes menores de idade.

Não serão aceitos:

- exposição de dados sensíveis;
- afirmações diagnósticas sem evidência;
- linguagem capacitista;
- assédio, discriminação ou intimidação;
- uso do projeto para vigilância não consentida.
