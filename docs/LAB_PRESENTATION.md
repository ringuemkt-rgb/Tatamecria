# NeuroJitsu — NEMO laboratory presentation / demonstracao de pesquisa

## Status as of 11 October 2026

**Academic software prototype only, not validated.** The system can
compute descriptive image-plane joint angles and body trajectories from
pose landmarks, store sessions, and compare repeated standardized
tasks under identical configuration. It does not establish clinical
improvement, learning, autism severity, treatment efficacy, or center
of pressure.

Branch: neurojitsu-lab-demo-2026-10.
Base: neurojitsu-academic-release-v1.
No institutional affiliation, endorsement or mentorship is implied.

## Demo A: recommended, no camera or human subjects

1. Use Python 3.11 or 3.12 in a virtual environment.
2. Install project: pip install -e ".[dev,api,dashboard]"
3. Execute: python scripts/run_lab_demo.py
4. Open: outputs/lab-demo/lab_longitudinal.html
5. Inspect: outputs/lab-demo/lab_longitudinal.json
6. Optionally run: streamlit run src/neurojitsu/dashboard/app.py
7. Run: pytest; ruff check src tests; mypy src/neurojitsu

The demo uses four deterministic synthetic sessions labelled as **synthetic
adult demonstration**; no camera, child, patient, diagnosis or clinical
benefit is involved. The trend is generated by the test function.

## Demo B: optional consenting adult with real webcam

Only if a local researcher and demonstrator agree and authorizations
and data governance are in place:

- Isolate workstation, single adult participant, operator supervised.
- Install the optional vision extra and SQLCipher dependency.
- Obtain and locally verify the official MediaPipe .task model file.
- Store the SQLCipher key in NEUROJITSU_DB_KEY (not in command history or git).
- Establish one fixed camera distance/height/view/lighting/calibration.
- Decide a standard task in advance; camera-based measurements are
  image-plane measurements, not calibrated meters or CoP.
- Explicitly document adult informed consent (separate from command flags).
- Execute the example command with local IDs (no names):

    python scripts/run_lab_capture.py --participant-id A001 --session-id LAB-A001-01 --task-id standing-task --camera-id labcam01 --calibration-id setup-v1 --model-path /secure/models/pose_landmarker.task --adult-consent-confirmed --single-adult-verified

**The flags record an operator attestation, not proof of consent.** Use
institutional consent records. A Haar facial detector can miss faces;
never claim guaranteed de-identification. Original frames stay in memory
in this path; derived data remain potentially re-identifiable. Do not
publish identifiable footage or pose traces.

## Demonstration order (5–7 minutes)

1. State the scientific question and clear non-clinical scope (30 sec).
2. Show synthetic frame→landmark→metric contract (60 sec).
3. Present four synthetic sessions and date-aligned metric changes (90 sec).
4. Change acquisition calibration in a test: comparison must be blocked (60 sec).
5. Inspect limitations and data quality / consent / encryption (90 sec).
6. Ask laboratory for advice on a simple adult reference-validation study.

## Critical scientific caveats

- A pose tracker is not an identity validator, especially for two people.
- Image-derived pelvis trajectories do not equal force-platform CoP.
- 2D angles vary with view/perspective, visibility, clothing and occlusion.
- More rapid movement is not inherently better movement.
- Changes between sessions may be practice, measurement error, maturation,
  camera geometry or genuine motor adaptation.
- No reliable technique recognition or two-person grappling is included.
- No child data allowed in a public demo or without ethics approval.
- Longitudinal reporting is descriptive, not causal inference.

## Proposed laboratory validation

Begin with consenting adults and one simple standardized task.
Define joint/segment metric, camera placement, angle reference,
minimum valid frames, missingness rules and sampling conditions.
Compare automated with manual/reference kinematics; report MAE/RMSE,
Bland–Altman bias and limits, ICC with confidence interval, SEM and MDC
when justified. Repeat across days and camera perturbations.

Only after strong task-specific evidence and separate institutional
ethics review should any child feasibility study be considered.

## Unresolved before a real institutional study

- independent reference validation and technical acceptance limits;
- clinical/target-population reliability and user tolerability;
- signed approved research protocol and institutional data custody;
- access control, threat modeling and key-recovery/deletion policy;
- camera calibration and single-person inclusion/quality assurance;
- formal agreement on supervision, funding, manpower, equipment;
- algorithmic error audit on skin tones, size, clothing and mobility.

**Recommendation:** present this to NEMO as an inspectable *measurement
research prototype* and invite technical critique, not as an already
validated monitoring tool for autistic children.
