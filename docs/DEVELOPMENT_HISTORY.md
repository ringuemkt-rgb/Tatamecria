# Development History

## Origin

NeuroJitsu began as a broader multimodal research concept for adapted BJJ, combining movement, participation, physiology, privacy and experimental sensing.

## 0.1 — Research foundation

Implemented:

- deterministic data contracts;
- session state machine;
- synthetic data;
- local storage;
- encrypted-storage path;
- reports;
- API/dashboard;
- basic kinematics;
- HRV utilities;
- privacy constraints.

## 0.2 — Motion Intelligence

Implemented:

- explicit biomechanical metric estimates;
- angle/ROM/path/smoothness/bilateral/trunk variables;
- body-region quality;
- occlusion/missing-frame metadata;
- phase ontology;
- Supervision integration;
- multi-person research scaffolding.

## 0.3 — Academic research release

The project was deliberately narrowed for academic presentation.

Primary focus:

- motor control;
- postural control;
- balance-related movement features;
- transparent metrics;
- laboratory validation;
- adapted-BJJ research.

Earlier experimental modules remain in the repository for reproducibility, but no longer define the central scientific claim.

## Why the narrowing matters

A master's project must be falsifiable and executable. The academic release therefore prioritizes:

```text
measurement validity
before
prediction complexity
```

and

```text
laboratory comparison
before
child deployment
```
