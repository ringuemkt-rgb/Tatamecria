# Research Use Cases for a Motor-Control Laboratory

## Module 1 — Markerless kinematic validity

**Population:** consenting adults.

**Tasks:** laboratory-selected standardized movements.

**Reference:** laboratory kinematics/manual reference.

**NeuroJitsu outputs:** joint angle, ROM, trunk inclination, trajectory.

**Primary outputs:** agreement, reliability, error, invalid-window rate.

## Module 2 — Postural-control measurement

**Population:** adults first.

**Reference:** force/pressure platform or other validated laboratory method.

**NeuroJitsu role:** complementary video feature extraction.

**Scientific aim:** identify which low-cost variables are worth retaining.

## Module 3 — Camera robustness

Test:

- distance;
- height;
- frontal/sagittal view;
- lighting;
- clothing/background;
- frame rate.

This module creates practical acquisition standards.

## Module 4 — Grappling occlusion

**Population:** two consenting adults.

**Tasks:** standardized standing and ground positions.

Measure:

- valid-landmark percentage;
- occluded duration;
- identity uncertainty;
- usable-window percentage;
- single vs two cameras.

This is a distinctive BJJ-specific motor-measurement problem.

## Module 5 — Motor learning / repeated practice

After validation, repeated standardized tasks can be used to study within-participant change over training sessions.

Potential variables:

- trajectory consistency;
- trunk strategy;
- bilateral difference;
- movement smoothness.

Interpretation must remain task-specific.

## Module 6 — Adapted-BJJ pilot

Only after the preceding stages:

- feasibility and safety;
- adherence;
- validated standardized motor outcome;
- laboratory/NeuroJitsu complementary measures;
- no diagnostic or autonomous behavioral inference.
