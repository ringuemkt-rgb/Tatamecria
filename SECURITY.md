# Política de Segurança

## Escopo

O NeuroJitsu Analytics é um MVP de pesquisa. Não é dispositivo médico, sistema diagnóstico ou ferramenta autônoma de decisão clínica.

## Relato responsável

Não publique vulnerabilidades contendo dados pessoais em issues públicas. Abra uma issue sem detalhes sensíveis solicitando um canal privado de contato com os mantenedores.

## Dados proibidos no GitHub

Nunca envie ao repositório:

- nomes, imagens ou vídeos identificáveis de crianças;
- prontuários ou termos de consentimento assinados;
- chaves SQLCipher, tokens ou senhas;
- modelos treinados com dados sensíveis sem revisão institucional;
- tabelas que permitam reidentificação.

## Requisitos de implantação

Dados reais exigem aprovação ética, consentimento, criptografia, controle de acesso, logs de auditoria e política institucional de retenção.
